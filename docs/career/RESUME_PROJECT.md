## A. AI 产品经理 / 产品实习方向

**广州泰迪智能科技有限公司 · AI 产品 / 应用实习项目**
**皮肤病变智能识别与辅助分析平台**（ResNet50 + FastAPI + React 端到端 Web 产品）

- 从真实需求出发定义产品：把「上传一张皮肤病变照片 → 得到良性/恶性倾向与可追踪记录」拆成
  上传、推理、结果解读、历史档案、对比、导出、账号与隐私 7 个模块，并写出可判定的验收标准
  （功能全流程可用、越权不可访问、图片磁盘上必须是密文、指标必须来自真实评测）。
- 主导模型指标口径与风险表述：确立「内部测试集」与「独立外部测试集」双口径，拒绝用
  92.96% 代表泛化能力，把外部 78.54%、恶性召回 65.49%、137 例恶性漏检如实写入产品说明与免责声明
  （禁用「确诊 / 已达到医生水平 / 临床级」等表述，并写成前端测试断言）。
- 设计面向隐私的产品流程：图片上传即剥离 EXIF、服务端加密落盘、历史图片需本人授权才解密展示、
  删除记录或账号时同步清除密文，并把这条链路写进「关于」页供用户查看。
- 用 AI Coding Agent 推进交付：把目标、非目标、架构约束、安全要求、测试标准与验收条件写成结构化提示词，
  结合人工评审与自动化测试迭代，最终交付 106 项后端测试 + 37 项前端测试 + 20 次端到端执行全绿的可用产品。
- 主动管理产品风险：在外部评测结果明显低于内部时，明确保留首次冻结模型的真实结果、
  不针对测试集调参，并把「泛化不足」列为下一版的首要改进项。

## B. FDE / AI 解决方案方向

**皮肤病变智能识别与辅助分析平台** — 端到端 AI 应用交付（需求 → 架构 → 模型 → 服务 → 前端 → 安全 → 测试）

- 独立完成从需求到可运行系统的落地：FastAPI + SQLAlchemy + SQLite 后端、React 18 + TypeScript 前端、
  PyTorch ResNet50 推理服务、Windows 一键启动脚本，覆盖注册登录、图像上传检测、结果可视化、
  历史档案、双记录对比、CSV 导出与账号管理全流程。
- 解决 AI 能力工程化的关键问题：模型进程内单例加载避免重复载入、训练/评估/服务共用同一份预处理实现
  （均值方差从 checkpoint 读回，杜绝口径漂移）、`BoundedSemaphore` 限制并发推理并设 30s 超时、
  阻塞前向放入线程池不占用事件循环、模型版本随每条记录落库并可回传前端。
- 交付可验证的模型结论：组织独立外部评测（797 张外部图片、冻结权重、一次性评测），
  确认与训练/验证/内部测试集 SHA256 重合为 0，并用独立脚本从预测结果重算全部指标（7/7 复核通过）。
- 把安全与隐私做成默认行为：Argon2id 口令哈希、HttpOnly 会话 Cookie、全量 CSRF 双重提交、
  越权一律返回 404、图像 Fernet 加密落盘、上传体积/像素/尺寸上限与路径穿越防护、日志脱敏。
- 建立交付质量基线：pytest 106 项、Vitest 37 项、Playwright 5 用例 × 4 浏览器、
  真实模型冒烟测试（API 与本地前向概率差 < 1e-4）、以及文档数字与链接的一致性检查脚本。

## C. AI 应用工程 / 算法工程方向

**皮肤病变智能识别与辅助分析平台** — PyTorch + FastAPI + React 全栈实现

- 训练与评估：ResNet50（ImageNet 预训练）+ 两阶段迁移学习（冻结 backbone 训头 3 epoch → 整体微调），
  类别权重、增强管线、混合精度、验证集选模型（ROC-AUC 为准）与早停；训练产出可复现元数据
  （版本、种子、超参、环境与 GPU 信息）。
- 反泄漏的数据工程：图像级 group-aware 分层划分（固定种子 42），把完全重复（SHA256）与
  近似重复（dHash ≤ 2）聚类成组并整组进同一划分，事后断言语义三重交集为 0；产出带
  `sha256/phash/group` 列的划分清单（train 1294 / val 276 / test 270）。
- 真实性能结论：内部留出测试集 Accuracy 92.96% / Recall 93.97% / ROC-AUC 0.9828；
  独立外部测试集（797 张）Accuracy 78.54% / Recall 65.49% / ROC-AUC 0.9079，
  并完成错误样本分析（FN 137 / FP 34）与阈值扫描分析（未应用）。
- 模型服务化：FastAPI + PyTorch 推理服务，进程内单例加载、共享预处理、并发上限与超时保护、
  健康检查同时反映数据库与模型状态，模型版本随记录持久化。
- 工程质量：后端 106 项 pytest（认证 / 检测 / 安全 / ML 管道）、前端 37 项 Vitest、
  5 个 Playwright 用例在 Chromium/Firefox/WebKit/移动端 4 个浏览器项目上执行，
  另有真实模型端到端冒烟与前端静态指标-vs-artifact 一致性校验脚本。
